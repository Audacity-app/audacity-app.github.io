Troubleshooting

Audacity troubleshooting on Windows — fix recording, playback & crash errors

Most Audacity errors on Windows fall into three categories: recording not working (permissions or device), no sound on playback (output device), or error opening sound device (exclusive mode or driver conflict). Start with the fix that matches your symptom.
Recording errors

Recording not working

No sound being recorded (flatline)
Mic permissions blocked or wrong device
Settings > Privacy > Microphone > enable; check device in Audacity Preferences
Error opening sound device
Exclusive mode conflict
Windows Sound > device > Properties > Advanced > uncheck exclusive mode
Recording stops after a few seconds
Temp folder full or disk space issue
Edit > Preferences > Directories > change temp folder to drive with space
Playback errors

Playback not working

No sound on playback
Wrong output device or volume zero
Audacity Preferences > Devices > Playback > select correct output
Playback crackling or distortion
Buffer underrun or sample rate mismatch
Increase buffer: Edit > Preferences > Devices > Audio to buffer (ms)
Audio out of sync after export
Sample rate mismatch between project and export
Set project rate to match recording: bottom-left Project Rate dropdown
Crash errors

Audacity crashing on Windows

Audacity crashes on launch
Corrupted preferences or plugin conflict
Delete audacity.cfg: %APPDATA%\audacity\audacity.cfg
Crash when applying an effect
Plugin bug or memory issue
Try with a shorter audio clip; update or remove the problem plugin
FAQ

Troubleshooting questions

Audacity not working after Windows Update

Windows updates often reset microphone permissions. Go to Settings → Privacy & security → Microphone and re-enable access. Also check if the audio driver was updated — sometimes driver updates change device names or capabilities.

How to reset Audacity settings on Windows

Delete the Audacity preferences file: close Audacity, then delete %APPDATA%\audacity\audacity.cfg. Audacity will recreate it with defaults on next launch. Your projects and recordings are not affected.
