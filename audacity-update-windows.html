Update guide

How to update Audacity on Windows — latest version guide

To update Audacity on Windows, download the new installer and run it over the existing installation. No uninstall needed. Your projects, settings and plugins are preserved.
How to update

Update Audacity to the latest version

  • 1

    Download the new installer

    Get audacity-win-3.7.3.exe from the download page.

  • 2

    Run it over the existing install

    Double-click and run. The installer detects the existing version and updates in place. No need to uninstall first.

  • 3

    Check version

    Help → About Audacity. The version should show 3.7.3.

Audacity also has a built-in update check: Help → Check for Updates. This opens the Audacity download page in your browser.
FAQ

Update questions

Will updating Audacity delete my projects?

No. Audacity projects (.aup3 files) and recordings are stored in folders you chose when saving — the installer never touches them. Settings and plugins are also preserved between updates.

After updating, my plugins are gone

Major version updates sometimes reset the plugin list. Go to Effect → Add / Remove Plug-ins → Rescan. Your plugins should reappear. If not, the plugin folder path may have changed — check Edit → Preferences → Modules.
