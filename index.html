Quick install

Install Audacity on Windows in 3 steps

  • 1

    Download the installer

    Click the download button above. The file is audacity-win-3.7.3.exe, about 35 MB.

  • 2

    Run and follow the wizard

    Double-click the .exe. If Windows SmartScreen appears, click More info → Run anyway. Accept the licence and click Install.

  • 3

    Set up your audio device

    Open Audacity → Edit → Preferences → Devices. Set Host to Windows WASAPI for best quality, or MME for compatibility.

FAQ

Common questions

Is Audacity free?

Yes. Audacity is completely free and open source software released under the GPL licence. There are no paid tiers, subscriptions or feature locks. The full application including all built-in effects and recording capabilities is free.

What is the latest Audacity version for Windows?

Audacity 3.7.3 is the current stable release for Windows as of mid-2026. Download it from the button above or from audacityteam.org.

Which audio host should I use in Audacity on Windows?

Windows WASAPI is recommended for most users — it provides higher quality recording and playback than MME. Use MME if WASAPI causes issues with your device. ASIO is for professional audio interfaces with dedicated drivers. See the WASAPI guide.
