Install tips

  • If SmartScreen appears, choose More info → Run anyway.
  • Allow microphone access in Windows Settings → Privacy & Security.
  • Use WASAPI host and loopback device to record system audio.

Quick answers

Is Audacity free and safe on Windows?

Yes. Audacity is free and open source. The 64‑bit Windows build is safe to install. Always download from a trusted link.

Which Windows versions are supported?

Current releases target Windows 10 and 11 (64‑bit). Older systems may require legacy builds.

How do I record system audio?

In Audacity, set the host to WASAPI and pick a loopback device to capture system audio (what‑you‑hear).
