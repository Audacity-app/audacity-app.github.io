Key features

Recording on Windows

Choose WASAPI to capture system audio (loopback) or use MME/DirectSound for microphones and line‑in.

Editing toolkit

Multi‑track timeline, spectral view, precise selection tools, fades, silence, noise reduction, and clip repair.

Effects & plugins

Supports VST3, LV2, LADSPA, and Nyquist. Many effects run in real time; expand your toolbox with third‑party plugins.

Format support

Work with WAV, AIFF, FLAC, OGG; export MP3. Add FFmpeg to import AAC, AC3, AMR and more.

64‑bit performance

Modern 64‑bit build for Windows 10/11, improved stability on large sessions and long recordings.

Accessibility

Keyboard shortcuts, zoom controls, and high‑contrast UI help you work faster and more comfortably.

Plugin support on Windows

Quick answers

Does Audacity support WASAPI on Windows?

Yes. Select WASAPI as the host to record system audio (loopback) or low‑latency input from supported devices.

Which plugins work on Windows?

VST3, LV2, LADSPA, and Nyquist plugins are supported. Some older VST may require bridging; ASIO builds are not bundled due to licensing.

What formats can I import or export?

WAV, AIFF, FLAC, OGG are supported natively, and you can export MP3. Install FFmpeg to import AAC, AC3, AMR and more.
