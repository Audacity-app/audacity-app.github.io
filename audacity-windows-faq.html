FAQ

Audacity Windows FAQ — download, recording, plugins & WASAPI

Quick answers to the most common Audacity questions on Windows: download, setup, recording problems, plugins and audio export.
Download & install

Download & install

Is Audacity free?

Yes. Audacity is completely free and open source software. No paid tiers, subscriptions or feature locks. Download from the download page.

What is the latest Audacity version for Windows?

Audacity 3.7.3 is the current stable release as of mid-2026. Download audacity-win-3.7.3.exe from the download page.

How do I update Audacity on Windows?

Download the new installer and run it over the existing version. No uninstall needed. See the update guide.

Does Audacity work on Windows 11?

Yes. Audacity 3.7.3 is fully supported on Windows 11. See the Windows 11 guide for permission setup.

Recording & audio

Recording & audio

Which audio host should I use — WASAPI or MME?

Windows WASAPI is recommended for most users. It has lower latency and supports loopback recording. Use MME only as a compatibility fallback. See WASAPI guide.

Audacity not recording — quick fix?

Check microphone permissions: Settings → Privacy → Microphone → enable all three toggles. Then restart Audacity. See full not recording guide.

How to record system audio in Audacity?

Set Host to Windows WASAPI, then select a device ending in (loopback) in the Recording Device dropdown. This records whatever is playing through your speakers.

Audacity system requirements 2026?

Windows 10 or 11 (64-bit), 4 GB RAM minimum, 500 MB disk space. See full requirements guide.

Plugins & effects

Plugins & effects

How to install VST plugins in Audacity?

Place .vst3 files in C:\Program Files\Common Files\VST3, then Effect → Add / Remove Plug-ins → Rescan. See plugins guide.

How to remove background noise in Audacity?

Effect → Noise Reduction → Get Noise Profile (from a silent section), then select all and apply. See noise reduction guide.

How to export MP3 from Audacity?

File → Export Audio → MP3 Files. LAME is built-in since Audacity 2.3.3. See MP3 export guide.
