Getting started

Getting started with Audacity on Windows — first recording guide

To get started with Audacity on Windows: install the app, set Host to Windows WASAPI, select your microphone, press the red Record button, speak, then stop. Export with File → Export Audio. Your first recording takes under 5 minutes to complete.
First recording

Make your first recording in Audacity

  • 1

    Set up audio

    Edit → Preferences → Devices → Host: Windows WASAPI → Recording: your microphone → Channels: 1 Mono.

  • 2

    Set recording level

    Click the microphone monitoring icon. Speak at normal volume. The level meter should peak between −12 and −6 dB. Adjust the input slider if needed.

  • 3

    Record

    Press the red Record button (or R). Speak or play. You will see a waveform appear in real time.

  • 4

    Stop and listen

    Press the square Stop button (or Space). Press Space again to play back your recording.

  • 5

    Export

    File → Export Audio → MP3 Files. Choose 128 kbps for voice. Click Save.

FAQ

Getting started questions

How do I undo in Audacity?

Press Ctrl+Z to undo the last action. Audacity supports unlimited undo history. Go to Edit → History to see all actions and jump to any point.

How do I save an Audacity project?

File → Save Project. Audacity saves as .aup3 (a single file containing all tracks and edits). To share with others or use in other software, use File → Export Audio to create a standard audio file (MP3, WAV, etc.).
