VST3 guide

Audacity VST3 plugins on Windows — install & fix guide

VST3 is the modern plugin standard supported in Audacity 3.2 and later on Windows. Place .vst3 files in C:\Program Files\Common Files\VST3, then run Effect → Add / Remove Plug-ins → Rescan to make them available.
Setup

Install VST3 plugins in Audacity on Windows

  • 1

    Install the VST3 plugin

    Run the plugin's installer. Most VST3 plugins install automatically to C:\Program Files\Common Files\VST3. If installing manually, place the .vst3 file or folder there.

  • 2

    Open Audacity and rescan

    Effect → Add / Remove Plug-ins → click Rescan. Wait for the scan to complete.

  • 3

    Enable the plugin

    Find your plugin in the list (it shows as "New"). Check the box and click Enable → OK.

  • 4

    Access in Effect menu

    The plugin appears in the Effect menu under its name or category.

VST3 path

Where does Audacity look for VST3 plugins?

Default VST3 location on Windows
# Standard VST3 location (Audacity scans this automatically):
C:\Program Files\Common Files\VST3\
# User-level VST3 (also scanned):
%LOCALAPPDATA%\Programs\Common\VST3\
# Audacity-specific plugin folder (for VST2 .dll files):
C:\Program Files\Audacity\Plug-ins\
FAQ

VST3 questions

Audacity VST3 not working — plugin not appearing

Check: (1) The .vst3 file is in C:\Program Files\Common Files\VST3 or a subfolder. (2) You have run Effect → Add / Remove Plug-ins → Rescan. (3) The plugin is 64-bit — Audacity 3.x does not load 32-bit plugins. (4) The plugin is not on the blacklist — check the Add / Remove Plug-ins list for it.

Does Audacity support VST3 on Windows?

Yes. Audacity 3.2 and later supports VST3 plugins on Windows. Place .vst3 files in the standard VST3 folder and scan via Effect → Add / Remove Plug-ins. VST3 offers better performance and features than the older VST2 format.
